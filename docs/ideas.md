# Ідеї для майбутніх розширень

Все, що більше за MVP і за одразу-очевидний беклог у `CLAUDE.md`. Чернетка — вільно переформульовувати, викидати, групувати.

## Налаштування (вікно або UI в треї)

Повернути пункт «Налаштування» у tray-меню, коли буде що там показати. Можливі секції:

- **Хоткеї.** UI для перехоплення комбінацій замість редагування `appsettings.json` вручну. Конфлікт із системними хоткеями треба попередити.
- **Мови.**
  - Цільова мова перекладу (DeepL підтримує UK, EN, DE, FR, JA, ZH і т.д.).
  - Мова OCR / вихідна мова тексту (en-US, uk-UA, ja-JP — для манги японською).
  - Швидкий перемикач прямо в трей-меню (без відкриття повного вікна налаштувань) — subMenu з 3-5 часто використовуваними парами «джерело → ціль».
- **Вікно результату.**
  - `FontSize`, `AutoHideSeconds`.
  - Стратегія позиціонування: біля виділення / по центру монітора / фіксована точка.
  - Колір рамки (світла/темна/обрати власний).
- **Логування.** Мінімальний рівень (Debug / Information / Warning), retention кількість днів.
- **Поведінка.**
  - Автозапуск з Windows.
  - Увімкнути/вимкнути попап «нема області» (`ShowCentered`).
  - Чи зберігати останню область між перезапусками.
- **Теми.** Готові палітри (pink pastel, blue, dark neutral, high-contrast) + можливість задати власну через кольори (рамка `ResultWindow`, обведення/заливка `SelectionRectangle`, фоновий overlay). Технічно — винести всі кольори в `ResourceDictionary` і підміняти рантайм (`Application.Current.Resources.MergedDictionaries`).

Технічно: при наявності вікна налаштувань найкращий кандидат — BlazorWebView (вже є у беклозі `CLAUDE.md`), бо більшість полів — прості form controls.
